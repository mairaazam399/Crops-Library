# Mobile (Expo) app - simple demo

This directory contains a minimal Expo-managed React Native app that lets you pick an image from the gallery, upload it to the backend, and display stubbed identification results.

Run (you need node + npm/yarn + expo-cli):

1. cd mobile
2. npm install
3. npx expo start

Set BACKEND_URL in App.js to point at your running backend (e.g., http://10.0.2.2:8000 for Android emulator, or your machine IP).
